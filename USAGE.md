# Как пользоваться ai-b2b-radar

Скилл ищет свежие AI-продукты, инструменты и модели в открытых источниках и оценивает, может ли продукт с такой функциональностью стать востребованным B2B-продуктом. Результат — типизированный JSON и самостоятельный HTML-дайджест.

## Быстрый старт

1. Установите скилл (см. [README](README.md)).
2. Запустите агента в папке, куда нужно сохранить отчёты.
3. Дайте запрос:

```text
/ai-b2b-radar Найди AI-технологии за последние 7 дней для B2B-клиентов банка. Рынок: Россия, сегмент: малый и средний бизнес. Подготовь полный дайджест: продукты, инструменты и модели отдельными категориями. Для моделей оцени широту применения, механизм экономии и открытые альтернативы. Ограничения на число продуктов нет
```

Вызов зависит от агента:

| Агент | Как вызвать |
|---|---|
| Claude Code | `/ai-b2b-radar <запрос>` |
| Другие агенты (Codex, Cursor, Gemini CLI…) | Назовите скилл в запросе: «Используй скилл ai-b2b-radar: …» |
| Ouroboros | После review и включения в **Skills** — тот же запрос в чате |
| claude.ai | Загрузите zip в Settings → Capabilities → Skills и напишите запрос в чате |

## Из чего состоит хороший запрос

Скилл берёт рамку исследования из запроса. Всё, что не указано, заменяется значением по умолчанию.

| Параметр | Пример | По умолчанию |
|---|---|---|
| Период | «за последние 7 дней», «с 1 по 15 сентября» | 7 дней до текущей даты (UTC) |
| Рынок | «Россия», «Казахстан», «глобально» | не задан; зарубежные кейсы помечаются с допущениями о переносимости |
| Сегмент | «малый и средний бизнес», «логистика», «клиники» | B2B разных отраслей |
| Задачи клиентов | «продажи и CRM», «документы и финансы» | продажи/CRM, поддержка, документы/финансы, закупки, операции, данные/ML |
| Размер выпуска | «ограничения на число продуктов нет», «топ-5 продуктов» | 8–12 продуктов, 4–6 инструментов, 3–5 модельных семейств |
| Акценты | «для моделей оцени механизм экономии», «сравни с российскими аналогами» | стандартная шкала из пяти критериев |

## Ещё примеры

Узкая ниша:

```text
/ai-b2b-radar Найди AI-продукты за последние 14 дней для логистических компаний. Рынок: Россия. Задачи: диспетчеризация, документы перевозки, звонки клиентов. Для каждого продукта найди российские аналоги и цены конкурентов.
```

Только модели:

```text
/ai-b2b-radar За последние 7 дней найди новые открытые модели и ML-методы, полезные бизнесу. Рынок: глобально. Нужны только модели: широта применения, механизм экономии, открытые альтернативы, лицензия.
```

Переоценка готового выпуска без нового поиска:

```text
/ai-b2b-radar Переоцени карточки из reports/ai-b2b-radar-2026-09-23-134335.json по текущей шкале. Новый поиск не проводи, собери новый выпуск.
```

## Что получится

В папке `reports/` рабочего проекта (в Ouroboros — в папке состояния скилла `data/state/skills/ai-b2b-radar/`; скрипты не пишут за её пределы):

- `ai-b2b-radar-YYYY-MM-DD-HHMMSS.json` — типизированный дайджест (схема `ai-b2b-digest/v4`);
- `ai-b2b-radar-YYYY-MM-DD-HHMMSS.html` — отчёт, открывается в браузере офлайн;
- сырые сигналы сбора.

В HTML:

- **Три рейтинга:** продукты, инструменты, модели — каждая категория ранжируется отдельно, баллы из 100.
- **Карточка:** описание, главные функции, покупатель, что продавать, экономический механизм — факты со ссылками отдельно от мнения агента.
- **Конкуренты:** таблица с типом, рынком, ценой, тем, что конкурент закрывает, преимуществом идеи и тем, где конкурент сильнее.
- **Оценка:** пять критериев по 20 баллов (боль, покупатель, ценность, повторяемость, причина выбрать) с обоснованиями, уверенность и способ проверить спрос.
- **Конкурентный ландшафт** и **покрытие источников** внизу страницы.

Сгенерировать HTML из готового JSON вручную:

```bash
python3 path/to/ai-b2b-radar/scripts/report.py reports/digest.json --output reports/digest.html
```

## Что учитывать

- **Нужны интернет и Python 3.9+.** Без сети скилл оценит только переданные ему материалы и так и напишет. Без Python сохранит JSON без HTML.
- **Один запуск — один выпуск.** Регулярный дайджест настраивается расписанием агента (например, `/schedule` в Claude Code).
- **Цены и ROI — гипотезы.** Рублёвые цены в карточках — предложения для проверки спроса, не тарифы найденных проектов. Выручку и размер рынка скилл не выдумывает.
- **Клиентов скилл не опрашивает.** Каждая карточка заканчивается гипотезой и способом её проверить; контакты с клиентами — только по прямому поручению.
- **Полный выпуск занимает время.** Скилл просматривает 80–150 сигналов и открывает страницы продуктов и конкурентов; рассчитывайте на длинную сессию агента.
